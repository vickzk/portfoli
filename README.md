# Vignesh T · Portfolio

Static portfolio site (HTML/CSS/JS, no build step) served by GitHub Pages from `main`.

Preview locally:

```sh
python3 -m http.server 8000   # then open http://localhost:8000
```

- `index.html`: all content
- `assets/css/style.css`: Kinetic Logic design tokens and layout
- `assets/js/main.js`: robot reel, scroll reveal, gallery filters, lightbox
- `assets/img/`: robot photos, company logos, `drone.svg` illustration, `og.jpg` share image
